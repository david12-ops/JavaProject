# JavaProject
# Očem je projekt?
Projekt umožňuje uživatelům mezi sebou si zprávy posílat. Uživatel si účet může vytvořit, upravit (změna hesla a profilového obrázku) nebo se přihlásit. V případě, že je přihlášený, tak i smazat, přidat, použít (vyměnit)  své další založené. Může též z tabulky přijatých zpráv ji odstranit. 
# Použité technologie a architektura
Psaná v Jave, pro package managment je použit Maven, pro uživatelské rozhraní JavaFX. Struktura projektu MVC (Model-View-Controller).
